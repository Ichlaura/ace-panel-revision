# ACE El Dorado — Portada blanca

Variante de la portada profesional original, con encabezado blanco y colores de marca: rojo #E82D3B, oro #E6BB33 y gris #393939. Conserva fotografía, buscador, filtros y páginas de demostración.

## Ejecutar
npm install
npm run dev
