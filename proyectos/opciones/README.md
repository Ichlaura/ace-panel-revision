# Directorio ACE — Capítulo El Dorado: opciones interactivas

Prototipo para aprobación visual con **tres estilos seleccionables** en la franja superior. Incluye Inicio, Directorio con búsqueda/filtros, perfil y simulación de panel administrativo.

## Ejecutar

```bash
npm install
npm run dev
```

Abrir la URL indicada por Vite. Para publicar en Vercel, importar este repositorio, usar framework **Vite** y comando de compilación `npm run build`.

## Avisos

- Todos los emprendimientos y sus datos son ficticios.
- Las fotos de demostración se cargan desde Unsplash y requieren internet.
- El símbolo ACE del encabezado es un **marcador provisional**: sustituirlo por el SVG oficial descargado del manual de marca antes de compartir como versión oficial.
- No hay autenticación, base de datos, edición real ni WhatsApp conectado. Es una demo de aprobación visual.
- No se han alterado archivos oficiales del logotipo.
