# Directorio ACE — Capítulo El Dorado

Prototipo funcional de frontend con React, Vite y TypeScript.

## Ejecutar

```bash
npm install
npm run dev
```

## Alcance de esta entrega

- Inicio institucional y emprendimientos destacados.
- Directorio con búsqueda y filtros por categoría y ciudad.
- Perfil de negocio con galería y enlaces de contacto (si se configuran).
- Diseño responsive y 12 categorías acordadas.
- Datos **ficticios** para probar el diseño.
