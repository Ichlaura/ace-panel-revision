# ACE Capítulo El Dorado — portada profesional

Prototipo React + Vite + TypeScript con portada fotográfica a pantalla completa, buscador funcional, filtros por categoría y ciudad, directorio, perfiles de ejemplo y panel de demostración.

## Ejecutar

```bash
npm install
npm run dev
```

## Importante

- Los emprendimientos son ficticios y las fotografías son demostrativas, cargadas desde Unsplash.
- El distintivo ACE es provisional. Sustituirlo por el SVG oficial descargado del manual de marca, sin alterar sus proporciones.
- El panel es una maqueta: no hay autenticación ni Supabase todavía.
- Se respetan los colores #E82D3B, #E6BB33, #393939 y la fuente Inter.
- La variante visual se cambia en la franja «Vista de aprobación» bajo la portada.
