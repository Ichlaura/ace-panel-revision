# ACE Capítulo El Dorado — Tres conceptos distintos

Prototipo de revisión con React + Vite + TypeScript.

- A: portal institucional (hero dividido y cuadrícula clásica)
- B: catálogo comercial (hero rojo, catálogo con menú lateral y tarjetas de producto)
- C: revista editorial (portada asimétrica, tipografía grande y cuadrícula editorial)

Todos usan la identidad cromática oficial e Inter. Las empresas y fotos son ficticias y el escudo mostrado es un marcador provisional: debe sustituirse por el SVG oficial autorizado.

## Ejecutar

```bash
npm install
npm run dev
```

Panel administrativo y contactos son simulaciones; no hay autenticación ni base de datos conectadas.
